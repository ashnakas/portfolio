💻 LeetCode Visualizer Redesign

A redesign of LeetCode to better support component skill acquisition through five core features:

  • Progressive Learning Pathways: unlock harder problems by mastering foundational ones
  • Real-World Explanation: real-life analogies to boost conceptual learning
  • Debugger Tool: live breakpoints and variable tracing
  • Brainstorm Mode: pair-programming with other users in real time
  • AI Chatbot Help: guided hints based on your own code

This redesign centers around reducing cognitive load while building up mastery incrementally.
