📁 Group Project: LeetCode Redesign

Title: Reimagining LeetCode for Learning

Team: Ashna Kasireddy, Christeena Joby, Evan Thomas, Ajay Krishnaswamy, Nathaniel Petersen

Overview: Redesigned LeetCode to support deeper learning using features grounded in learning science, such as AI Chatbot Help, Progressive Learning Pathways, Real-World Problems, Debugger Tool, and Brainstorm Mode.

Highlights: Presented user-centered design decisions and usability testing insights; emphasized metacognition, scaffolding, and collaborative learning in our redesign.

🚀 Final Project: Space Safari

Overview: Interactive educational game for children to learn about the solar system through quizzes and exploration. Designed with multimedia learning principles, gamification, and accessibility in mind.

User Testing: Conducted with 3 users including Jason and Adhish. Insights led to added features like a leaderboard, clearer navigation, error feedback, and drag instructions.
